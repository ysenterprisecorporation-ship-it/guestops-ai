宿泊予約・清掃引継ぎリスク診断

対象施設：架空施設 A　診断対象：架空の2026年12月予約　データ元：サンプルOTA・PMS予約CSV

見本専用：予約番号・宿泊日・金額はすべて架空。実際の施設診断・リアルタイム監視を示すものではありません。

要約

診断項目結果推奨対応
OTA予約とPMS予約の対応要確認 1件施設・部屋・予約のID対応を照合
同一泊の競合候補 1件予約の有効性と部屋割を確認
同日入替の清掃確認事項 1件退去後の清掃予定・完了確認

優先度 高：PMS予約欠落候補

根拠：OTA側で予約 DEMO-201（12/11～12/13）が有効。入力されたPMSデータ内で同一予約IDを確認できない。

解釈：予約IDの対応付けがない可能性もあるため、「PMSに予約がない」とは断定できない。PMS/OTAで現在の予約状態を確認する。

具体的対応：①OTAで予約詳細・宿泊日を確認 ②PMSで施設・部屋・予約IDを照合 ③差異が解消するまで該当日の在庫を空室と判断しない ④確認日時と担当者を残す。

優先度 高：同一泊の競合候補

根拠：DEMO-301 と DEMO-302 が12/14の宿泊日に重なる。

具体的対応：①実予約の部屋割と有効状態を確認 ②二重販売なら施設の正式運営手順で優先対応 ③予約変更・キャンセルは必ず正本OTA/PMS側で認可のもと実施。

優先度 中：チェックアウト当日の清掃引継ぎ

根拠：DEMO-401 が12/20退去、DEMO-402 が12/20到着。

具体的対応：①清掃担当を確定 ②入室可能時刻と作業完了予定を確認 ③作業完了記録を残す。単なる同日入替は予約重複ではない。

成果物の構成（実案件）

①予約状態差異の一覧 ②重要度・確認すべき根拠 ③日別清掃確認事項 ④再発防止チェックリスト ⑤未検証データの一覧。分析対象は提出された匿名CSVに限定し、最新のOTA在庫・法令遵守・利益改善効果を保証しません。
