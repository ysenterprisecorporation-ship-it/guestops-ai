このデモの位置づけ

宿泊運営者向けの予約・清掃リスク診断の試作版です。Beds24・Booking.com・Airbnbとは接続せず、ページ内の架空予約データまたは手元の匿名CSVを使用します。

販売在庫を変更しません。 検出結果は最新のOTA/PMS在庫を証明しません。予約の修正・販売再開は必ず元の管理画面で確認してください。

必要列：source,id,arrival,departure,status（英語見出し）。日付はYYYY-MM-DD、statusはconfirmed/cancelled。sourceはOTAまたはPMSを識別する任意の名称です。

氏名・メール・電話・身分証・決済情報を含むファイルは投入しないでください。ブラウザー内で処理し、外部送信機能はありません（外部スクリプト不使用）。

有料の詳細診断について

この無料ツールは架空データまたは匿名化済みCSVの一次チェックです。提供データの新旧・欠落やPMSとOTA間の予約番号対応付けまでは証明しません。

追加の運営診断では、例外リストの確認、清掃・予約引継ぎの改善手順、判断記録テンプレートを納品します。費用・納期・対象範囲は申込前に書面で確定します。
