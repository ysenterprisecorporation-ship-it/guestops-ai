## 決済確認・納品の順序
1. Squareの注文・決済情報を公式APIまたは管理画面で再照合する。通知、購入完了画面、自己申告だけでは決済成立と判定しない。
2. 注文ID・決済ID・金額・商品・購入者メール・決済日時を照合し、重複注文と既存の送信状態を確認する。未確認、返金、異常値は納品停止・要確認とする。
3. 購入者用の非公開リンク台帳から該当商品の教材を特定する。台帳の実URL・ファイルIDはGitHub、公開サイト、営業メール、一般公開資料へ転記しない。
4. 教材の共有権限が既定の購入者向け設定に一致し、購入者に編集権限を与えないことを確認する。リンクを知る人が閲覧できる設定では、転送による第三者閲覧を防げない点に注意する。
5. 決済確認済みの購入者にのみ案内を送信する。送信前に送信状態を永続化し、送信結果が不明な場合は自動再送せず要確認にする。
6. 送信後の不達・アクセス拒否を追跡する。再納品前にも注文ID・決済状態・過去送信状態を照合する。
