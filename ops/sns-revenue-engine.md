# SNS Revenue Engine — Project ③

## KPI
reach -> profile/action -> inquiry -> Square visit -> order -> revenue -> profit

## Content families
1. Problem recognition
2. Self-diagnosis
3. Before/After workflow
4. Concrete mini-template
5. Failure pattern / myth correction
6. Case-style operational example using no invented client facts

## CTA ladder
Low friction first:
- save/checklist
- reply/comment with keyword
- read pinned diagnostic
- inspect existing Square offer
- purchase

## Automation boundary
Automate draft generation, repurposing, content calendar, classification, and KPI aggregation.
Do not automate mass unsolicited DMs, mass replies, follow/unfollow, or browser actions that bypass platform rules.

## Required post format
Hook
-> operational pain
-> self-recognition
-> practical insight
-> one next action

Each post must teach something useful even if the reader never buys.
